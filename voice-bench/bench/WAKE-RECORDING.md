# 웨이크워드 녹음 요청 — "픽스야"

파트 C(음성) / 최승원

램프를 부르는 말을 **"픽스야"** 로 정했습니다. 이 말을 알아듣는 모델을 만들려면
여러 사람의 목소리가 필요합니다. **한 사람당 10분**이면 됩니다.

## 왜 여러 사람이 필요한가

한 사람 목소리로만 학습하면 그 사람만 부를 수 있는 램프가 됩니다.
심사 때 다른 사람이 불러서 안 깨어나면 그 자리에서 끝납니다.

기성 영어 모델을 그대로 쓸 수 없다는 것은 확인했습니다. 한국어 발화를 들려줬을 때
**심사 문장 6개 중 2번 잘못 깨어났습니다.**

## 준비

노트북에서 합니다. 마이크는 노트북 내장이면 충분합니다.

```bash
pip install sounddevice soundfile numpy
```

저장소를 받고(또는 `bench/wake_record.py` 파일 하나만 받아서):

```bash
python bench/wake_record.py --name 본인이름
```

## 어떻게 진행되나

화면이 시키는 대로 Enter 를 누르고 말하면 됩니다. 순서는 이렇습니다.

| 단계 | 내용 | 시간 |
| --- | --- | --- |
| 1 | 방 소리 10초 (아무 말 안 함) | 10초 |
| 2 | **"픽스야"** 20번 — 말투를 바꿔 가며 | 5분 |
| 3 | 헷갈리는 말 12개 + 평범한 문장 6개 | 4분 |

**조용한 방에서, 마이크와 30~50 cm 거리**를 지켜 주세요.
너무 작거나 소리가 넘치면 프로그램이 다시 하라고 합니다.

## 세 가지 다 필요합니다

**말투를 바꾸는 이유** — 같은 조로만 20번 말하면 표본이 20개가 아니라 1개나
다름없습니다. 평소 말투, 작게, 크게, 빠르게, 천천히, 멀리서, 고개 돌린 채,
말끝 올려서("픽스야?"), 혼잣말하듯. 화면이 매번 알려줍니다.

**헷갈리는 말이 더 중요합니다** — "픽", "믹스", "식스", "픽셀", "박스" 같은 것들입니다.
이게 없으면 램프가 아무 때나 깨어납니다. "픽스야"는 2음절 이름에 호격이 붙은
짧은 말이라 일상 대화와 부딪힐 여지가 큽니다.

**방 소리**는 학습 증강에 쓰고, 발화 감지 임계값을 정하는 데도 씁니다.
