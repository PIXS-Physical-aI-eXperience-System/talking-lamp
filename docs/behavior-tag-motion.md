# 인지 모델의 행동 태그를 모터에 연결하기

문장을 직접 입력하면 `src/cognition/send_text_turn.py`가 인지 모델을 호출한다. 모델은 대사와 행동 태그를 JSON으로 돌려준다. 스크립트는 대사와 행동을 화면에 보여준다.

기본 실행은 모터를 움직이지 않는다.

```bash
python3 src/cognition/send_text_turn.py --text "안녕 픽스" --labels "사람"
```

Jetson에서 실제 모터를 움직일 때에는 ROS와 브리지 노드를 먼저 실행한다. 팔을 받치고 움직임을 지켜볼 사람이 있을 때만 `--execute`를 붙인다.

```bash
source /opt/ros/jazzy/setup.bash
source jetson_ws/install/setup.bash
python3 src/cognition/send_text_turn.py --text "안녕 픽스" --labels "사람" --execute
```

`lamp_interaction`은 `/lamp/cognition/response`에서 검증된 JSON을 받는다. 허용된 행동은 최대 두 개다. 노드는 이를 `/lamp/play_motion` 액션으로 순서대로 보낸다. 형식이나 강도가 잘못된 행동은 모터로 보내지 않는다.

`nod`는 손목의 위아래 관절만 움직인다. 동작 중에는 나머지 네 관절을 현재 각도에 유지한다. 동작이 끝나면 기존의 idle 움직임이 다시 이어진다.

첫 실물 시험에서 강도 0.5의 손목 변화는 약 4.4도였고, 사용자는 더 커도 된다고 했다. 그래서 `nod`에만 손목 배율 `NOD_WRIST_GAIN = 2.0`을 적용한다. 2026-10-29 재시험에서 손목 변화는 약 8.4도였고 사용자는 잘 됐다고 확인했다. 시험 전후 어깨 온도 값은 34°C와 43°C였다. 짧은 시험에서 오른 폭이 커서 원인을 다시 측정해야 한다.

현재 입력 라벨은 수동으로 지정한다. 카메라 라벨을 자동으로 가져오는 연결은 후속 작업이다. 이 경로는 마이크와 별개이므로 음성 대화의 응답 형식을 바꾸지 않는다.

## S4 자리 비움과 복귀

`lamp_interaction`은 `/lamp/vision/presence`도 받는다. 비전은 얼굴이 5초 동안 보이지 않으면 `false`를 보낸다. 노드는 그 뒤 `away_after_s`(기본 20초, 2026-10-30에 30초에서 줄임) 동안 더 기다린다. 그 사이 얼굴이 다시 보이면 아무 동작도 하지 않는다. 음성 대화가 진행 중이면 대기 시간을 다시 시작한다.

자리 비움으로 판단하면 얼굴 추종을 끄고 `/lamp/away_pose`에 `true`를 보낸다. 모션 브리지는 이를 `away.hold`로 바꿔 Pi에 보낸다. Pi는 손으로 기록한 대기 자세(`AWAY_POSE`, 베이스 정중앙, 몸 낮춤, 헤드 위)로 3초에 걸쳐 이동한다. 모델이 예측한 어깨 유지 토크는 0.62N·m로 80% 한도 0.785N·m 안이다. 어깨 온도가 45°C를 넘거나 Jetson 연결이 끊기면 자세를 푼다.

대기 자세에서는 헤드가 위를 향해 지나가는 얼굴을 잠깐 잡을 수 있다. 그래서 얼굴이 2초 이상 계속 보여야 복귀로 처리한다. 복귀하면 `away.clear`로 3초에 걸쳐 원래 자세로 돌아오고, 3.5초 뒤 `wake_up`을 강도 0.5로 한 번 재생한다. 조명을 서서히 끄는 동작은 조명 모듈이 나온 뒤에 붙인다.

2026-10-29 실물 시험에서 30초 뒤 대기 자세로 이동했고 2분 17초 동안 유지했다. 복귀 2.2초 뒤 일어나 인사했고, 사용자는 자세와 동작이 만족스럽다고 확인했다. 대기 자세를 오래 유지할 때의 어깨 온도는 아직 측정하지 않았다.

### 복귀 뒤 얼굴 추종과 자동 중앙 복귀 정리 (2026-10-30, 코드만)

복귀 인사(`wake_up`)가 끝나면 얼굴 추종을 `greet_follow_s`(기본 10초) 동안 켠다. 인사 뒤 얼굴이 화면 밖으로 밀려 자리 비움이 다시 시작되던 문제를 막기 위해서다. 그 사이 음성 대화가 시작되면 추종을 끄고 S2에 넘긴다. S2는 방향 정렬 뒤 추종을 다시 켠다. 대화 중에 창이 끝나도 추종을 끄지 않는다.

비전 노드는 관절 각도가 없을 때 20초 간격으로 `return_center`를 다시 보냈다. 자기가 보낸 중앙 복귀 뒤에도 E가 몇 초 더 `busy`를 내는데, 이를 다른 동작으로 오인했기 때문이다. 이제 자기 중앙 복귀 뒤 5초 안의 이름 없는 `busy`는 무시한다. 또 `/lamp/away_pose`가 `true`인 동안에는 휴식 자세를 해제하고 자동 중앙 복귀를 하지 않는다.

2026-10-30 실물 시험에서 복귀 직후 얼굴이 화면 위쪽 끝(y 약 110/1080)에 있었다. 대기 자세의 헤드가 서 있는 사용자를 잡고, 원래 자세로 내려가면 얼굴이 위로 벗어나기 때문이다. 그래서 얼굴 추종을 0.3초마다 최대 2°로 빠르게 하고(`ImageFollowConfig`), 손목 범위를 시작 자세 기준 ±20°로 넓혔다(`FaceFollowLayer.MAX_WRIST_FROM_HOME_DEG`). 재시험에서 추종을 켠 지 6초 만에 얼굴이 화면 세로 중앙(y 525)에 왔고 손목은 12° 들렸다. 10초 뒤 원래 자세로 돌아간 뒤에도 앉은 얼굴이 화면 안에 남았다.

같은 시험에서 어깨 과열 정지(55°C)가 어깨 실측 35°C인데도 걸린 적이 있다. 온도 값 하나가 튄 것으로 보고, 최근 5회(1초 간격) 측정의 중앙값으로 판정하도록 바꿨다(`hardware_backend.py`). 수정 뒤 시험에서는 정지가 걸리지 않았다.

추종이 꺼진 상태에서 base yaw가 1초 안에 13°에서 -43°로 크게 돈 일이 두 번 있었다. Pi 디바이스 데몬의 소리 방향 회전으로 추정하며, 마이크 작업이 보류 중이라 원인은 확인하지 않았다.
