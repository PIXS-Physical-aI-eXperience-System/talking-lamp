## 1. 팀 소개

- AI 모델 개발, 컴퓨터 비전, 하드웨어 설계 등 서로 다른 분야의 5명으로 구성
- 소프트웨어와 하드웨어를 함께 다루는 구성이라, AI 추론부터 서보 제어와 기구·전원 구성까지 외주 없이 전 과정을 팀 내에서 수행함
- 1인 1파트로 나누되, 조립과 통합 구간은 전원이 참여함

**소프트웨어 4인**

| 이름 | 파트 | 하는 일 |
| --- | --- | --- |
| 주경태 | 인지 | VLM으로 상황을 판단하고 대사와 행동을 결정함 |
| 김태현 | 시스템통합 | 전체 실행 순서와 상태를 관리하고 파트 간 연결을 조율함 |
| 최승원 | 음성 | 듣고 말하는 처리 전반 (음성 인식·합성, 에코 제거, 소리 방향) |
| 김아현 | 비전 | 카메라로 물체·얼굴 위치를 찾고 조명 목표 지점을 계산함 |

**하드웨어 1인**

| 이름 | 파트 | 하는 일 |
| --- | --- | --- |
| 이수혁 | 움직임 + 하드웨어 | 관절 각도 계산과 모션 생성, 서보 구동, 전원·기구·조명 구성 |

## 2. 목적 및 개발 내용

- 카메라로 주변 상황을 인식하고, VLM이 대사와 행동을 결정하는 온보드 시스템 구현
  - 서보모터로 반응, 조명 자동 배치, 음성 대화를 수행함
- 클라우드 없이 기기 내부에서 모든 AI 추론이 독립 동작하는 완전 온보드 구조 실현
  - Jetson Orin Nano와 Raspberry Pi 5 두 보드로 구성
- 생각하는 동안에도 로봇이 멈춰 보이지 않게 함
  - AI가 대답을 만드는 데는 2~3초가 걸림
  - 고개를 돌리거나 시선을 맞추는 반응은 그동안에도 끊기지 않아야 함
  - 이 둘을 나눠 처리함

## 3. 프로젝트(아이템) 개요 및 핵심기술

### 아이템 개요

- 책상 위에 놓는 관절형 AI 로봇 스탠드
- 카메라와 마이크로 주변을 인식함
  - VLM이 대사와 행동을 결정해 고개를 돌리거나 조명을 배치하고 음성으로 대화함
- 인터넷 없이 완전 동작함
  - AI 추론은 Jetson Orin Nano에서 처리
  - 서보 구동과 실시간 모션은 Raspberry Pi 5가 담당

### 핵심기술

**온보드 VLM** : 상황을 보고 무엇을 말하고 무엇을 할지 결정함

- 입력 : 카메라 이미지 1장과 음성 인식 텍스트
- 출력 : 한국어 대사와 행동 태그
- 모델 : InternVL3.5-2B
- 방식 : 커스텀 학습 없이 상용 가능 라이선스의 사전학습 모델을 양자화해 사용
  - 양자화 : 모델 내부 숫자를 성글게 저장해 메모리를 줄이는 기법

**2보드 역할 분리** : AI 연산이 모터 제어를 방해하지 않게 함

- 조건 : 모터에는 0.01초마다 초당 100번 명령을 보내야 하고, 간격이 일정해야 부드러움
- 문제 : 같은 보드에서 AI 연산을 돌리면 명령이 밀려 움직임이 덜컥거림
- 해결 : 계산하는 보드(Jetson)와 모터를 돌리는 보드(Pi)를 나누고 Ethernet으로 직결

**온보드 추론 통합** : 8GB 안에 AI 모델 네 종류를 함께 올림

- 구성 : VLM, 음성 인식(STT), 음성 합성(TTS), 비전 검출기를 Jetson에서 동시 구동
- 제약 : 8GB를 CPU와 GPU가 공유함
- 관리 : 모델 파일 크기가 아니라 프로세스가 실제 점유하는 피크 메모리로 예산을 잡음
  - 통합 상한은 7.2GB

**4계층 반응 구조** : 느린 판단과 빠른 반응을 갈라놓음

- 문제 : 대화 판단은 초당 1회 이하지만, 살아있는 느낌은 100ms 안에 나와야 함
- 구성 : 조명 배치(L3), 인지(L2), 반사 추종(L1), 대기 모션(L0)을 주기가 다른 계층으로 분리
- 합성 : 네 계층의 출력을 모션 블렌더에서 우선순위로 합침

**칼만 필터 기반 서보 제어** : 흔들리는 검출값을 부드러운 움직임으로 바꿈

- 구조 : 5축 관절 (Base Yaw / Base Pitch / Elbow Pitch / Wrist Roll / Wrist Pitch)
- 보정 : 얼굴 검출 노이즈를 칼만 필터로 제거
- 변환 : 역기구학으로 조명 목표점을 관절 각도로 바꿔 부드러운 궤적을 만듦

**단안 카메라 기반 3D 공간 인지** : 깊이 센서 없이 물체 위치를 구함

- 전제 : 램프가 책상에 고정되어 있고 대상이 책상 위에 있음
- 원리 : 등록된 책상 평면과 카메라 광선이 만나는 점이 곧 3D 위치

**Voice 파이프라인** : 듣고 말하는 전 과정을 기기 안에서 처리함

- 흐름 : 웨이크워드 → 에코 제거 → 음성 인식 → VLM → 음성 합성
- 호출어 : 오픈소스로 한국어 전용 모델을 직접 학습
  - 상용 SDK의 인터넷 인증 의존을 제거함
- 마이크 : 에코 제거와 소리 방향 추정은 XMOS XVF3800의 하드웨어 기능을 활용

**기성 부품 기반 하드웨어 구성** : 자체 PCB 없이 검증된 부품을 조합함

- 서보 : 기성 버스 서보 드라이버 보드
- LED : 서브 MCU 개발보드
- 전원 : 계통별로 분리 구성

### 활용 도구 및 장비

| 구분 | 내용 |
| --- | --- |
| AI 보드 | Jetson Orin Nano 8GB Developer Kit |
| 실시간 제어 보드 | Raspberry Pi 5 (Ethernet으로 Jetson과 직결) |
| 서브 MCU | STM32 / ESP32 (LED 제어, 안전 정지 검토) |
| 액추에이터 | 서보모터 5축 (Feetech STS3215 12V 계열, 데이지체인) |

| 마이크 | XMOS XVF3800 원형 4마이크 어레이 (하드웨어 AEC·빔포밍·DOA 내장, USB) |
| 서보 드라이버 | 기성 버스 서보 드라이버 보드 (USB 연결) |

| 개발 언어 | Python, C++ (MCU 펌웨어) |
| AI 프레임워크 | PyTorch, TensorRT, Hugging Face |
| 협업 도구 | GitHub, Notion |

### 수행 단계

**1단계. 착수·설계**

- LeLamp 원본 조립과 MuJoCo 시뮬레이션 검증
- 시스템 아키텍처 확정
- VLM 후보 벤치마크
- 하드웨어 부품 선정·발주
- 런타임 이벤트 스키마 확정

**2단계. 단독 동작**

- Jetson 환경 구축
- Voice 파이프라인 온보드 구동
- 시뮬레이션 기반 IK·모션 블렌더 개발
- 검출 결과를 3D 타겟점으로 변환
- 전원·서보 결선 검증

**3단계. 통합**

- 온보드 VLM 구동과 최적화
- 행동 태그 파이프라인 연결
- 시나리오별 순차 통합 (호명·대화 → 조명 배치 → 나머지)
- 헤드 무게 실측 반영

**4단계. 완성**

- 외형 조립
- 전체 통합 테스트
- 시연 영상 제작
- 경진대회 출품 준비

### LeLamp 기반 개조

외형·기구를 백지에서 설계하지 않고 오픈소스 로봇 램프 [LeLamp](https://github.com/humancomputerlab/LeLamp)을 기반으로 삼되, 본 주제에 맞게 아래를 변경·추가해 진행함.

**그대로 가져오는 것**

- 5축 관절 구조와 3D 기구 파일, 조립 문서
- Feetech 서보와 서보 통신 계층
- 모션 프리미티브 11종
- MuJoCo 시뮬레이션
  - 하드웨어 없이 모션 개발을 먼저 시작할 수 있음

**우리 주제에 맞게 바꾸는 것**

- **AI를 클라우드에서 온보드로** (이 프로젝트의 핵심)
  - 원본은 음성 인식·대화·합성을 전부 외부 서버로 호출함
  - 이를 전부 기기 안에서 처리하도록 교체함
- **보드를 1개에서 2개로**
  - 원본은 단일 보드 구성임
  - AI 연산이 모터 제어 주기를 흔들지 않도록 AI 보드와 실시간 제어 보드를 분리함
- **작업 조명 신규 추가**
  - 원본의 LED는 표정 표현용이라 책을 비추는 조명이 없음
  - 광원과 방열 구조를 새로 설계함
- **한국어 대응**
  - 원본은 영어 전용으로 고정되어 있음
  - 프롬프트, 음성 인식·합성, 호출어를 전부 한국어로 재구성함
- **모션을 재생에서 합성으로**
  - 원본은 녹화된 동작을 그대로 재생함
  - 역기구학·칼만 필터·모션 블렌더를 새로 만들어 상황에 맞는 움직임을 생성함

세부 변경 목록과 근거는 [파트-분배.md 부록 A](파트-분배.md)에 정리함.

## 관련 자료

**Ongo** : https://ongolamp.com/

- 감성 인터랙션 로봇 스탠드
- 공개 페이지에 제품명과 컨셉 문구 외에 상세 기능·가격·기술 사양이 아직 공개되어 있지 않음
  - 온보드 AI 여부, 클라우드 의존 여부 등 불명
  
**EMOTION 논문** : https://arxiv.org/abs/2410.23234

- LLM의 맥락 학습 능력으로 인간형 로봇의 표정·제스처·비언어적 동작 시퀀스를 동적으로 생성하는 프레임워크
- 언어에서 행동으로의 매핑에 가까움
- 상황에 맞는 표현적 제스처를 생성해 사용자 연구에서 인간 조작자 수준 이상의 평가를 받음
- 모션 파트의 표현 모션 설계에 참고 가능

**ELEGNT 논문** : https://arxiv.org/abs/2501.12493

- 비인간형(램프 형태) 로봇의 표현력 있는 움직임 설계를 다룸
- 기능적 목적(조명 배치 등)과 표현적 요소(의도·관심·감정 전달)를 결합한 설계 프레임워크를 제시함
- 사용자 연구에서 표현 중심 움직임이 사용자 참여도와 로봇 인식을 크게 향상시킴을 입증함
- L0/L1 표정·반응 모션 설계의 핵심 참고문헌이며, 원문 PDF를 `docs/reference/`에 확보해 둠
