# 모션 스택 후속 개선 백로그

이 문서는 통합 PR #3을 정리하는 과정에서 확인했지만 해당 PR의 범위를
넓히지 않기 위해 보류한 개선 사항을 관리한다. 우선순위는 안전 영향과
외부 입력 노출 가능성을 기준으로 한다.

## P0 · 앱 종료 시 장치 안전 정리

- 상태: 미착수
- 영향 파일: `lelamp_runtime/main.py`, `lelamp_runtime/smooth_animation.py`
- 현상: 두 LiveKit 진입점은 모터 서비스를 시작하지만 작업 종료 콜백을
  등록하지 않는다. RGB 또는 세션 초기화가 중간에 실패하거나 작업이
  종료되면 모터 서비스의 `stop()`을 거치지 않을 수 있다.
- 위험: sleep 자세 확인과 torque off가 생략되어 임의 자세에서 모터가
  활성화된 채 남을 수 있다.
- 권장 변경:
  - 장치 서비스 시작을 트랜잭션처럼 처리해 이후 서비스 시작 실패 시
    이미 시작한 서비스를 역순으로 정리한다.
  - 중복 호출해도 안전한 앱 단위 `close()`를 제공한다.
  - LiveKit `JobContext.add_shutdown_callback()`에 비동기 정리 함수를
    등록한다.
- 완료 조건:
  - 정상 종료, 부분 초기화 실패, 세션 시작 실패에서 모터와 RGB 정리가
    각각 한 번 실행되는 자동 테스트가 통과한다.
  - 실기기에서 정상 종료·SIGINT·SIGTERM·직렬 통신 실패 시 sleep 복귀와
    torque off를 확인한다.

## P1 · 인지 입력 검증

- 상태: 미착수
- 영향 파일: `src/motion/kalman.py`
- 현상: 위치, 원점, 방향과 측정 표준편차에 대해 크기·유한값·양수 검증이
  없다. NaN 위치는 필터 상태를 오염시키고 영벡터 방향은 원점의 위치
  측정처럼 처리될 수 있다.
- 권장 변경:
  - 위치·원점·방향은 정확한 3차원 유한 벡터만 허용한다.
  - 방향 벡터는 0이 아니어야 하고 측정 표준편차는 유한한 양수여야 한다.
  - 잘못된 샘플은 기존의 마지막 정상 추적 상태를 바꾸지 않고 거부한다.
- 완료 조건:
  - NaN, infinity, 잘못된 shape, 영방향, 0 이하 측정 노이즈에 대한 회귀
    테스트가 통과한다.
  - 잘못된 샘플 뒤에도 마지막 정상 추적 상태가 유지된다.

## P1 · 실패한 IK 목표 활성화 방지

- 상태: 미착수
- 영향 파일: `src/motion/layers.py`
- 현상: `TaskLightLayer.place()`와 `reach()`는 IK가 수렴하지 않아도 계산된
  관절값을 활성 목표로 저장하고 envelope를 연다.
- 위험: 도달 불가능한 목표를 받으면 명령을 거부하는 대신 관절 한계에
  가까운 근사 자세로 움직일 수 있다.
- 권장 변경:
  - 입력 벡터를 먼저 검증한다.
  - `IKResult.converged` 또는 문서화된 오차 한계를 만족할 때만 목표를
    활성화한다.
  - 실패 시 기존 활성 상태와 유지 자세를 보존하고 호출자에게 명확한
    실패 결과를 반환한다.
- 완료 조건:
  - 도달 불가능한 목표가 레이어를 활성화하지 않는 테스트가 통과한다.
  - 이전의 유효한 작업 조명 자세가 실패한 새 요청으로 덮어써지지 않는다.

## P1 · Jetson–Pi 통신 계약 구체화

- 상태: 후속 미들웨어 구현 전에 진행
- 영향 파일: `docs/Jetson-Pi-모션-연동-개발계획.md`
- 필요한 항목:
  - 버전이 포함된 NDJSON envelope와 명령별 payload/result schema
  - 좌표계 이름, 축 방향과 SI 단위
  - 상태·오류 코드와 Action feedback/result 매핑
  - 재연결, 요청 ID 중복 제거와 재실행 금지 규칙
  - Pi mock 서버와 Jetson 클라이언트가 공유하는 golden vector
- 완료 조건: 서로의 구현을 보지 않고 만든 Pi·Jetson 양쪽 구현이 동일한
  golden vector와 loopback 계약 테스트를 통과한다.

## P2 · 정적 검사와 CI 범위 확장

- 상태: 미착수
- 영향 파일: `Makefile`, 향후 `.github/workflows/`
- 현상: 현재 lint 대상은 `src/motion`, `tests`, `sim/*.py`이고 수정된
  `lelamp_runtime`은 포함하지 않는다. GitHub Actions 검사도 없다.
- 완료 조건:

  - 기본 Ruckig 테스트, analytic fallback 테스트, lint와 manual hardware
    test 미수집 검사가 PR에서 자동 실행된다.
