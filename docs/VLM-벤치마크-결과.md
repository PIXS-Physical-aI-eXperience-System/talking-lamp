# VLM 벤치마크 결과 (A파트 · 주경태)

**목적:** VLM 모델 확정 + 근거 (진행-순서 A 순번 1~2, 인수인계 1번)
**상태:** 자원·품질 측정 완료. **최종 선정은 아키텍처 방향(한국어 직접 vs 영어+번역) 결정에 종속** → B(김태현)·C(최승원) 협의 필요.

## 1. 자원 (메모리·속도)  · 단위 GB

이미지: 원본 4080×3060 (12.5MP), 448/700은 축소.

| 모델 | 이미지 | 가중치(cuda) | cuda 피크 | VLM 총 | 시스템 피크 | 추론 |
|---|---|---|---|---|---|---|
| InternVL3.5-2B | 원본 | 1.99 | 2.58 | 3.38 | ~6.1 | 29.7s |
| InternVL3.5-2B | 448 | 1.99 | 2.58 | 3.28 | - | 28.5s |
| **Qwen2-VL-2B** | 448 | **1.39** | **1.46** | **2.20** | ~4.8 | **9.3s** |
| Qwen2-VL-2B | 700 | 1.39 | 1.49 | 2.21 | ~4.9 | 8~21s |
| Qwen2-VL-2B | 원본 | - | - | ❌ OOM(보드 다운) | - | - |

- **InternVL: 이미지 축소 무효** - 원본 ↔ 448 cuda 2.58 동일. 원본 사용이 화질 이득.
- **Qwen: 원본만 OOM**(12.5MP). 448~700(~0.4MP)은 메모리 ~1.4GB(cuda)로 거의 동일·안전.
- **Qwen이 InternVL보다 메모리 −1.3GB, 속도 3배.** 둘 다 Apache 2.0.
- 추론 시간은 출력 길이 비례 (영어 짧은 답 ~8s / 한국어 128토큰 풀 ~20s).
- ⚠️ **둘 다 목표 2~3s 미달** - bitsandbytes INT4 런타임 문제.

## 2. 품질 (test_real: 웃는 사람 + 노트북/코드, 밝음, EXIF 회전 보정)

| 출력 언어 | InternVL3.5-2B | Qwen2-VL-2B |
|---|---|---|
| **한국어** | 장면 읽음(헤드셋→"음악 듣는 듯" 추론). 영어 섞임·혼입 있음(필터로 처리) | ❌ 실패 (질문 따라쓰기, 이미지 무시) |
| **영어** | 정확·상세 (화면 폴더명까지 읽음) | 정확·간결 |

- **두 모델 다 영어=강, 한국어=약.** 한국어 강제 지시가 특히 Qwen을 무너뜨림 → **영어로 물으면 Qwen 정상 작동.**
- **혼입(한자/가나) 2단 방어:** ①디코딩 억제(`--suppress-cjk`) ②후처리 필터(`ko_lite.sanitize_for_tts`). TTS엔 한자·가나 안 감. 영어는 C(최승원) TTS가 처리.
- 초기 "의자" 테스트셋은 용도 불일치라 폐기, 사람+작업장면으로 재측정.

## 3. 핵심 결정 & 추천

**지금 관건은 딱 하나 — Qwen2-VL-2B vs InternVL3.5-2B 중 무엇을 쓸 것인가.**

| 항목 | Qwen2-VL-2B | InternVL3.5-2B |
|---|---|---|
| VLM 메모리 | **1.9GB** ✅ | 3.2GB |
| 추론 속도 | **~8s** ✅ | ~29s |
| 영어 장면 인식 | 정확·간결 | 정확·상세(화면 글자까지) |
| 한국어 직접 출력 | ❌ 실패(이미지 무시) | △ 됨(영어섞임·지저분) |
| 이미지 처리 | 448~700 필수(원본 OOM, 700이 성능면에서 더 좋음) | 원본도 됨(축소 무효) |
| 라이선스 | Apache 2.0 | Apache 2.0 |

### 추천: **Qwen2-VL-2B** (영어 출력 + 번역 구조 전제)

- **이유:** 메모리 절반·속도 3배라 통합/실시간에 유리, 통합 예산(7.2GB) 여유 큼. 영어에선 장면을 정확히 읽음. 둘 다 Apache 2.0라 라이선스는 동률.
- 한계: 한국어 직접 생성은 못 함 → 아래 파이프라인으로 해결.

### 추천 방식 (파이프라인)

```
카메라 이미지 → Qwen2-VL-2B (영어로 상황판단 + 대사·행동태그)
             → 한국어 번역 (~0.3s) → C(최승원) TTS
```
1. VLM은 **영어** 로 판단·생성 → 정확·깨끗
2. 짧은 문장 번역으로 한국어화
3. 약한 한국어를 VLM이 직접 짜내는 것보다 품질↑

### 대안

**InternVL3.5-2B + 한국어 직접 출력 + 2단 혼입 필터.** 추가 부품 없이 한국어가 바로 나오지만 무겁고 느림.
