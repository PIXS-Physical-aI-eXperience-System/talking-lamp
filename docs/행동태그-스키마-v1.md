# 행동 태그 JSON 스키마 v1 (Talking Lamp · A파트 인지)

**작성:** 주경태(A·인지)
**목적:** LLM이 만든 답을 **대사(say) + 행동(actions)** 으로 분리해 B(라우팅)·C(음성)·E(모션)에 넘기는 **공통 계약**
**상태:** 초안 v1 — **B(김태현)·E(이수혁) 사인오프 대기.** 합의되면 동결.
**근거:** `src/motion/primitives.py`(E)의 `CLIP_NAMES`·`play_primitive` 실제 코드 확인 반영

---

## 0. 왜 필요한가

LLM에게 그냥 물으면 `"안녕! (고개 끄덕이며 밝아진다)"` 처럼 **말과 동작이 섞여** 나온다.
- C(TTS)에는 **대사만** 가야 함 (안 그러면 괄호·설명까지 소리내 읽음)
- E(모터)에는 **동작 이름만** 가야 함

그래서 LLM 출력을 아래 형식으로 **강제**하고, 파서가 안전하게 뜯어 각 파트로 보낸다.

---

## 1. 스키마 (v1)

```json
{
  "say": "안녕하세요! 오랜만이에요",
  "actions": [
    { "tag": "nod", "intensity": 0.6 }
  ],
  "end_turn": true
}
```

| 필드 | 타입 | 필수 | 기본 | 흐름 | 설명 |
|---|---|---|---|---|---|
| `say` | string | ✅ | — | → B → **C(TTS)** | 스피커가 읽을 **대사만**. 한국어, 2문장 이내, 기호·괄호설명 금지 |
| `actions` | array | ✅ | `[]` | → B → **E(모터)** | 재생할 동작 목록. 없으면 빈 배열. **최대 2개** |
| `actions[].tag` | enum | ✅ | — | `rt.play_primitive(tag)` | 아래 11종 중 하나 (E의 CSV와 동일) |
| `actions[].intensity` | number | ✕ | `0.5` | `scale = 기본scale × intensity` | 동작 세기 0.0~1.0 |
| `end_turn` | bool | ✕ | `true` | → **B 상태머신** | 대화 턴 종료 여부 |

> `say`는 `play_primitive`가 아니라 음성 경로로 감. 관절 각도는 넘기지 않음(보드 경계는 "프리미티브 이름"만 — 파트-분배 2.3절).

---

## 2. tag 허용값 (11종 고정)

E의 모션 CSV(`recordings/*.csv`)와 1:1. **이 목록 밖은 금지.**

| tag | 언제 | tag | 언제 |
|---|---|---|---|
| `nod` | 긍정·수긍 | `sad` | 슬픔·아쉬움 |
| `headshake` | 부정·거절 | `shy` | 쑥스러움 |
| `curious` | 궁금·되물음 | `shock` | 놀람 |
| `excited` | 신남·환영 | `scanning` | 두리번(탐색) |
| `happy_wiggle` | 기쁨 표현 | `wake_up` | 호명에 깨어남(S2 시작) |
| `idle` | 기본 대기(동작 없음) | | |

---

## 3. E 코드와의 매핑 (확인된 사실)

`rt.play_primitive(name, **load_kw)` → `Primitive.load(name, sign, scale, loop)`

| 스키마 필드 | E 지원 | 매핑 |
|---|---|---|
| `tag` | ✅ | `name` (11종) |
| `intensity` | △ | E의 `scale`은 **관절 5개 배열** → 스칼라 intensity를 배열로 매핑하는 규칙 **E와 합의 필요** |
| `loop` | (v1 미노출) | 필요 시 추가. 기본 idle만 loop |
| ~~`speed`~~ | ❌ | play_primitive에 속도 인자 없음 → **v1 제외** |
| ~~`repeat`~~ | ❌ | 반복 횟수 인자 없음 → **v1 제외** |
| ~~`led`~~ | ❌ | LED는 Pi의 rgb 서비스(별도 채널) → **v1 제외, B와 소관 확인 후 v2 검토** |

---

## 4. 파서 규칙 (안전장치)

LLM이 항상 완벽한 JSON을 주지 않으므로 파서가 방어한다.

1. **enum 밖 tag → 무시하고 `idle`로 대체** (LLM이 없는 동작을 지어내도 안 죽게)
2. **JSON 파싱 실패 → `say`만 살리고 `actions: []`** (앞뒤 잡소리 제거 후 재시도)
3. **`say` 정화** → 한자·가나·이모지·괄호설명 제거 (`ko_lite.sanitize_for_tts` 재사용)
4. **`actions` 최대 2개** 초과분 버림
5. **`intensity`** 범위 밖이면 0.0~1.0으로 클램프

---

## 5. 데이터 흐름

```
LLM 원문
   │
[파서]  ── say ─────────► B ──► C(TTS, 한국어 음성)
   │
   └──── actions[] ─────► B ──► E(rt.play_primitive(tag, scale))
   │
   └──── end_turn ──────► B(상태머신: 말하기→대기)
```
